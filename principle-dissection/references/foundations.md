# 常见基本功领域:判错概念 + 验收题(第 3 步用)

> 这是**审核要的那套基础**,不是产出要的那套。
> 一个概念够不够格进来,只有一个标准:**它能不能让你看出「这是错的」。**
> 目标不是"学完",是**过线**——过线的标志是:**给我一个错的,我能指出来。**

## 怎么用

1. 第 3 步先标出**承重**的黑箱层。
2. 在下面找到对应领域,取出那层的「判据概念」。
3. **只学这几条,别顺着展开。**(展开就是通用清单——你上次说的"网上下载的地图"。)
4. 用「验收题」自测:**答不出 = 没过线。**

## 一个领域的「基础」长什么样

不是文档目录。是三样东西:

- **判据概念**:让你能说"这算对 / 这算错"的最小概念。
- **典型错法**:错了通常长什么样(失效模式的那一版)。
- **验收题**:一个具体的、错的东西——你要能指出它错在哪。

---

## 1. 编程 / 软件

- **判据概念**:变量与作用域、控制流、数据类型与隐式转换、边界(0/1/空/最大)、值与引用、错误处理路径。
- **典型错法**:类型用了错的、边界差一(off-by-one)、异常被吞当正常、改了副本以为改了原件。
- **验收题**:下面两段各错在哪——
  - 遍历列表时边遍历边删除元素,期望删掉所有偶数。
  - 函数返回内部列表的引用,调用方一改,原对象也跟着变。
- **过线就够了**:不必能手写快排;要能看出"这段在空输入 / 单元素上会崩"。

## 2. 并发 / 分布式

- **判据概念**:原子性、顺序与可见性、一致性(线性化)、幂等、部分失败、"没收到响应" ≠ "没发生"。
- **典型错法**:检查后使用之间状态被改(TOCTOU)、重试造成重复副作用、做了一半没回滚、把超时当失败。
- **验收题**:一个"扣款 - 加款"流程,假如中途崩溃只做了一半,你的代码会处于什么状态?
- **过线就够了**:不必会手写 Raft;要能看出"这里两个操作之间能被插进来"。

## 3. 数据 / 存储

- **判据概念**:schema 与约束、事务原子性、索引与查询计划、缓存 vs 源、迁移与版本兼容、NULL 语义。
- **典型错法**:先查后写没有事务、缓存改了源没改、旧数据喂新代码崩、把 NULL 当空串。
- **验收题**:并发两笔转账,总额守恒会在哪一步被打破?
- **过线就够了**:不必会调优;要能看出"这里缺少一个事务/唯一约束"。

## 4. 数值 / 科学计算

- **判据概念**:浮点不是实数、精度与累积误差、单位与量纲、量级/条件数、比较要用容差。
- **典型错法**:浮点直接 `==` 比较、大数吃小数、单位(米/秒、秒/毫秒)混用、累加顺序敏感、除零 / NaN 传播。
- **验收题**:`0.1 + 0.2 == 0.3` 为什么可能是 False?这会让哪段**判定**出错?
- **过线就够了**:不必会数值分析;要能看出"这里不该用等号比浮点"。

## 5. 统计 / 从数据得结论

- **判据概念**:抽样与偏差、相关 ≠ 因果、显著性 vs 效应量、多重比较、置信区间、幸存者偏差。
- **典型错法**:把相关当因果、把 p 值当"结论为真的概率"、多重比较不校正、样本选择有偏。
- **验收题**:一份报告说"A 与 B 相关,所以做 A 能提升 B"——它缺了哪一步?
- **过线就够了**:不必会推导公式;要能看出"A 只是 B 的一个代理变量"。

## 6. 机器学习 / LLM

- **判据概念**:训练 vs 推理、过拟合/欠拟合、数据泄漏、评测集污染、分布漂移、LLM 的幻觉与上下文上限。
- **典型错法**:测试集泄漏进训练、挑好看的指标报、"模型说了所以对"、拿 in-distribution 分当泛化能力。
- **验收题**:一个模型在评测上 95%,怎么判断它是真会还是**在背**?你该看什么?
- **过线就够了**:不必会训模型;要能看出"这个评测集和训练集同源"。

## 7. 操作系统 / 系统

- **判据概念**:进程/线程、内存与生命周期、文件句柄、路径与权限、编码、阻塞与调度。
- **典型错法**:句柄泄漏、路径含空格/中文没引用、GBK vs UTF-8 读错、假设"这步一定很快"。
- **验收题**:一个后台程序跑一夜就卡死,最可能是什么**耗尽**了?
- **过线就够了**:不必会写内核;要能看出"这里没有关掉句柄"。

## 8. 网络 / 协议

- **判据概念**:分层、请求/响应与状态码、超时与重试、幂等、TLS、双向 vs 单向、限流。
- **典型错法**:无限重试放大故障、把 5xx 当永久失败、忽略半开连接、信任未校验的输入。
- **验收题**:接口超时了——对方其实成功了吗?你的重试会因此做什么?
- **过线就够了**:不必会手写 HTTP;要能看出"这个重试没有幂等保护"。

## 9. 数学

- **判据概念**:定义、定理、**合法的推演步**(定义展开 / 引用已知结论 / 显式不等式)、量词、充分 vs 必要、反例。
- **典型错法**:"显然"跳步、把充分当必要、量词顺序搞反(`∀∃` vs `∃∀`)、只在特例上验证就推广。
- **验收题**:给一段推导,指出**哪一步没有依据**——注意:不是"算错了",是"根本没理由"。
- **过线就够了**:不必会独立证定理;要能看出"这一步是凭空出现的"。

## 10. 安全

- **判据概念**:认证 vs 授权、最小权限、输入一律不可信、注入、密钥管理、越权。
- **典型错法**:把身份校验当成权限校验、拼字符串构造查询、密钥写进日志、出错默认放行。
- **验收题**:一个接口"登录了就能调",这算做了权限吗?凭什么这么说?
- **过线就够了**:不必会挖漏洞;要能看出"这里把 user 传进来的 id 直接当成了身份"。

---

## 收尾:这张表不是让你从头学

是让你在**某一个产物**上,几十秒内找到它要的那 3–6 个概念,然后拿一道验收题问自己:

> **给我一个错的,我指得出吗?**

- 指得出 → 过线,回去继续拆。
- 指不出 → 只学那几条,别展开。

**"看不懂"和"审不了"是两回事**;这一步治的只是后者。
