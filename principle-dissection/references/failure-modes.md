# 失效模式清单(第 3 步逐项对照用)

> 用法:**逐条**对照,不点头。对每条停顿三秒问:**「如果它发生,我会看到什么?」**
> 如果答案是"**看到什么都一样**"——那就是它了。
>
> 每一组末尾有"怎么验"。验不了 ≠ 不用管;写成"未验证,列为已知边界"也比假装没有强。

---

## 1. 时序 / 并发

- [ ] 竞态(两个操作交错产生的坏结果)
- [ ] 锁序不一致 → 死锁
- [ ] 丢失唤醒 / 信号早于等待
- [ ] 顺序依赖(结果取决于"谁先到")
- [ ] 非原子读-改-写(检查后使用之间状态被改)
- [ ] 依赖"同一瞬间"的假设

**怎么验**:缩小/放大并发、加随机延迟、跑几千次;有状态机就上 TLA+;有服务就上 Jepsen/Maelstrom。

## 2. 失败处理

- [ ] 部分失败(做了一半,另一半没做)
- [ ] 超时(超时后对方其实成功了)
- [ ] 重试放大(重试让故障更糟)
- [ ] 幂等缺失(重复执行 = 重复副作用)
- [ ] 错误被吞(异常当正常路径)
- [ ] 降级静默(出错后悄悄走了别的路)

**怎么验**:故障注入(chaos-mesh / chaostoolkit);把依赖掐掉再跑。

## 3. 状态

- [ ] 缓存陈旧(源变了,缓存没变)
- [ ] 内存与持久不一致
- [ ] 重启 / 崩溃恢复
- [ ] 迁移 / 版本兼容(旧数据喂新代码)
- [ ] 全局可变状态串台

**怎么验**:重启进程看结果;喂旧版本留下的数据;关掉缓存再跑对比。

## 4. 输入

- [ ] 空 / 无 / 零元素
- [ ] 超大(几百万、超长字符串)
- [ ] 边界(0、1、最大值、最大+1)
- [ ] 非法字符 / 控制字符
- [ ] Unicode 归一(NFC/NFD 不等)
- [ ] 类型混淆("1" vs 1 vs true)
- [ ] 编码不一致(GBK 读 UTF-8)

**怎么验**:属性测试(Hypothesis)自动造边界;或手写边界样例。

## 5. 时间

- [ ] 时区(本地 vs UTC 混用)
- [ ] 夏令时切换
- [ ] 闰年 / 闰秒
- [ ] 时钟回拨(单调 vs 墙钟)
- [ ] 耗时假设("这步一定 <1 秒")

**怎么验**:把系统时间往前后拨;跨时区跑;伪造慢时钟。

## 6. 资源

- [ ] 泄漏(内存 / 句柄 / 连接 / 线程)
- [ ] 上限(达到就崩,没有背压)
- [ ] 队列积压(生产快于消费)
- [ ] 磁盘满 / 文件描述符耗尽

**怎么验**:长时间跑看曲线;人为压小上限;灌满队列。

## 7. 数值

- [ ] 浮点精度 / 累积误差
- [ ] 溢出 / 下溢
- [ ] 整除取整方向(负数的 `//` 和 `%`)
- [ ] 单位混用(米/英尺、秒/毫秒)
- [ ] NaN / Inf 传播

**怎么验**:和参考实现对拍(差分测试);专门喂极端数值。

## 8. 环境 / 路径

- [ ] 路径分隔、空格、中文、超长路径
- [ ] 编码(Windows GBK vs UTF-8)
- [ ] locale(小数点逗号、大小写规则)
- [ ] 大小写不敏感文件系统(Windows)
- [ ] 当前工作目录变了

**怎么验**:换目录跑;路径里塞中文和空格;换 shell。

## 9. 外部依赖

- [ ] 版本漂移(依赖悄悄升级)
- [ ] 对方限流 / 封 UA
- [ ] 网络分区 / 半开连接
- [ ] 静默降级(接口返回变了但没报错)

**怎么验**:钉死版本跑;断开网络;看对方返回体字段是否变。

---

## 收尾:把"怎么验"折成第 4 步的动作

对照完,把**"适用且我现在没防"**的项挑出来,**至少一项**转成第 4 步要真跑的 oracle。挑不出来,说明这份对照太客气了。
