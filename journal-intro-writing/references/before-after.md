# 逐句改造对照：文献摘要式 → AE 式

> 用一个中性例子说明改写手法。主题是"空气污染暴露场的构建方法"。
> 左栏是典型的失败写法，右栏是对应的 AE 式写法。**注意变化的是句式与信息取舍，不是知识量。**

---

## 对照 1：起手段

**❌ 文献摘要式**

> Smith 等（2018）发现 PM₂.₅ 暴露与心血管疾病显著相关（RR=1.12）。Jones 等（2019）在中国的研究得到类似结论。Lee 等（2020）进一步指出臭氧也存在类似效应。

**✅ AE 式**

> 长期暴露于细颗粒物与臭氧与心血管及呼吸系统疾病相关[1–3]。在污染较重的地区，这类健康负担已被量化到可观规模，且高度依赖所用暴露指标——同一时期，一个指标下降 18%，另一个指标的健康影响反而上升 5%[4]。

**改了什么**

| 动作 | 说明 |
|---|---|
| 主语从「作者」换成「现象」 | 读者跟着论证走，不用记谁做了什么 |
| 三篇合并成一组引用 | `[1–3]` 替代三个独立句子 |
| 删掉具体 RR 值 | 引言不需要这个精度 |
| 加一个"指标依赖"的论点 | 这才是要引出的问题 |

## 对照 2：方法谱系段

**❌ 文献摘要式**

> 2015 年，A 等提出了 Voronoi 邻域平均法，在美国本土的 R² 为 0.72。2016 年，B 等比较了克里金和土地利用回归，发现克里金的 RMSE 更低。2018 年，C 等提出了 Downscaler，用两个高斯过程建模，MCMC 估计，计算很慢。2020 年，D 等改进了 Downscaler，用 REML 估计，速度提升。

**✅ AE 式**

> 融合方法的谱系相当宽。最简的一路是对观测做空间插值、不引入模型信息，在站点较密时足以复现时间变化，但留出检验下往往抓不住空间梯度[5,6]；把模型信息纳进来的做法以偏差修正为核心[7]。统计建模路线以 Downscaler 为代表——把观测对模式输出做线性回归，截距与斜率均为空间变系数、经 coregionalization 耦合，此后扩展到时空错位与年度第四高值[8,9]；其计算瓶颈则通过极大似然或可扩展贝叶斯回归化解[10,11]。

**改了什么**

| 动作 | 说明 |
|---|---|
| 按**类别**组织，不按**年份** | 插值类 / 偏差修正类 / 统计建模类 |
| 每类一句"做法 + 局限" | 一句到位，不展开公式 |
| 方法名 + 括注代表文献 | `Downscaler[8]`，不写"A 等提出了 Downscaler" |
| 删掉 R²、RMSE、速度提升 | 这些属于 Results |
| 四年四篇压成两句话 | 信息量不减，篇幅减半 |

## 对照 3：缺口段

**❌ 文献摘要式**

> 虽然有很多方法，但每个方法都有缺点。因此需要进一步研究。

**✅ AE 式**

> 然而，现有比较几乎都在同一范式内进行：回归模型之间比较预测变量[12,13]，地统计模型之间比较空间相关结构[14]，机器学习算法之间比较超参数[15]。跨范式的比较极为有限[16,17]，原因多半在于实施不同方法所需的分析工作量与专业门槛。**尤其缺乏的，是机器学习与地统计方法之间的直接对照。**

**改了什么**

| 动作 | 说明 |
|---|---|
| 缺口必须**具体到"缺哪一种比较"** | 不能停在"需要进一步研究" |
| 五步结构 | 主张 → examples → 反例 → 原因 → 具体缺口 |
| 用 Despite / However / Although / very limited | AE 的标准转折词 |

## 对照 4：本文路线段

**❌ 文献摘要式**

> 本文做了很多工作。首先，收集了 8 个数据集。其次，用交叉验证比较了它们。然后，分析了长期趋势。最后，做了集成。

**✅ AE 式**

> 本文不做方法排名，也不发布新的集成数据集。我们把 8 个融合数据集统一到 2003—2019 年、CONUS 12 km 网格与政策相关臭氧水平指标上，覆盖从确定性插值到机器学习的完整谱系，并沿同一条分析链依次检验：日尺度比较基础、区域长期轨迹、趋势断点与网格斜率格局。在此基础上，以逐日截尾均值作为中心估计、以保留成员的最小值与最大值作为范围，检验"中心—范围"能否同时呈现共识与选择差异。

**改了什么**

| 动作 | 说明 |
|---|---|
| 删掉「首先/其次/然后/最后」 | 这类词是列表标记，不是论证连接 |
| 用"覆盖…的完整谱系"替代逐条列举 | 一句话交代范围 |
| 用冒号 + 逗号串列举 | 句内并列，不换行 |
| 明确"不做"什么 | AE 常用 "we do not …" 划清边界，反而显得有主张 |

## 一个可量化的判断

把改写前后的稿子各跑一遍：

| 指标 | 文献摘要式 | AE 式 |
|---|---|---|
| 段落数 | 12–20 | 5–7 |
| 以作者名开头的句子 | 多 | **0** |
| 单篇结果数字 | 8–15 个 | **0–2 个** |
| 成组引用占比 | <20% | **>60%** |
| 缺口段是否存在 | 通常没有 | **必须有** |
| 「首先/其次/最后」 | 有 | **0** |

如果一段话删掉作者名就不成立，它就不是引言该有的段落。
