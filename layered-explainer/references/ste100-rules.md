# ASD-STE100 规则详解与中文移植

> 来源：ASD-STE100 *Simplified Technical English* 国际规范（Part 1 Writing Rules / Part 2 Dictionary）。
> 该规范由 ASD（Aerospace, Security and Defence Industries Association of Europe）维护，正式文本是 **付费版权物**。
> 本文件是公开规则的转述 + 我做的工作化整理，**不是**规范的替代品，也不含批准词表。

## 一、它到底是什么

1980 年代，欧洲航空航天业发现：飞机维修手册由多国译者、多母语读者共同使用，一句歧义可能就是一次事故。于是他们把手册语言**规则化**成一套受控自然语言：

- 词汇受控：只用一批**批准词**，每个词**只有一个意思、一个词性**
- 句法受控：句长、语态、时态都写死
- 目的不是优美，是**不可误读**

Karpathy 的观点是：这套 40 年前为「避免歧义危险」设计的东西，恰好是今天读大模型长输出的解药。

## 二、Part 1 写作规则（要点）

### 句子
| 规则 | 数值 |
|---|---|
| 程序句（指令）最长 | **20 词** |
| 描述句最长 | **25 词** |
| 一句指令数 | 1（不要「并且/然后」串烧） |
| 一段主题数 | 1 |
| 一段句数 | ≤ 6 |
| 名词串最长 | 3 词 |

### 语态与时态
- **主动语态**；程序用祈使句（`Close the valve.`）
- 只用简单时态：不定式、祈使、一般现在、一般过去、过去分词作形容词、`will` + 动词
- **不用**完成时（`has done`）、**不用**进行时（`is running`）、**不用**被动（`is closed by`）

### 词汇
- 只用批准词，且**只按批准的那个词性用**：
  - `test` 批准为名词 → `do a test`，不写 `test the unit`
  - `oil` 批准为名词 → 不写 `oil the valves`
  - `close` 批准为动词 → 「靠近」必须写 `near`，不写 `close to`
- **一个词一个意思**：`follow` 只有「在后面」的意思，没有「遵守」的意思
- 不用同义词换着说：同一事物全文同一个词
- 允许在规则内使用**技术名词**（Technical Names）和**技术动词**（Technical Verbs），例如部件名、专用操作

### 版本差异
各版本/来源的批准词数说法不一：有 **~875**、**~865**，较新的 Issue 9 口径是 **~900 个基础词**，另有 **~1,200 个需替换的词**。引用时用「约 900」并注明口径不定。

## 三、中文移植对照（无官方规范，按规则精神）

中文没有批准词表，也没有 20 词的官方上限。以下是**我做的移植**，不是 STE100 原文：

| STE100 规则 | 中文对应做法 |
|---|---|
| 20 / 25 词 | 20 / 25 **字** |
| 一句一指令 | 一句一事，逗号不连着堆三个动作 |
| 主动语态、祈使句 | 少用「被」；操作步骤直接写动词 |
| 不用完成时/进行时 | 少用「已经…了」「正在…着」这类冗余 |
| 一词一义一词性 | 术语全文统一：不要「模型 / 大模型 / LLM」混用 |
| 不用被动 | 少用「由…负责 / 被…所」 |
| 名词串 ≤3 | 少堆定语：`发动机滑油压力传感器故障指示灯` 要断 |
| 一个词一个意思 | 首次出现的术语给一句话定义 |

**中文特有的稀释结构**（STE100 里没有，但同样是歧义源）：

| 别写 | 写 |
|---|---|
| 进行检测 / 实施测试 / 作出判断 | 检测 / 测试 / 判断 |
| 予以确认 / 加以说明 | 确认 / 说明 |
| 有效地提升 | 提升（要留就给出数字） |
| 一定程度上 / 值得注意的是 / 综上所述 | 删 |
| 能够 | 能 |

## 四、怎么用

```bash
# 1. 让模型按 STE100 风格重写
#    提示词：「用 ASD-STE100 风格解释 <主题>。主动语态、短句、一句一指令。」
# 2. 跑检查器
python scripts/ste_lint.py <重写后的文件>
# 3. 看报告，改掉超长句和稀释词
```

**报告只给 candidate。** 完整批准词表是 ASD 的版权物，本仓库不含，因此任何本地脚本都无法判定「合规」。对用户表述用：

> ✅ 「按 STE100 规则收紧过，超长句 12 处已修。」
> ❌ 「符合 STE100。」「STE100 合规。」

嫌太严格时，Karpathy 建议的降级口径是「达到 ASD-STE100 的 80% 程度」——**降的是严格度，不是跳过检查**。
