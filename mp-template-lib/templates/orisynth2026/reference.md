# 人工复核结果（2026-10-08）

复核方法：读 `sample.html` 原始标签定位（按 `text-decoration: underline`、`font-size: 36px`、
`<img` 逐个数）→ 对照 `preview.png`（2304×12914 整页图，从版头到版尾品牌落版）。

## 结论：这个模板几乎没有 CSS 装饰，辨识度全在图和字上

- `border` / `background` / `background-image` / `border-radius` / `box-shadow` 的声明数**全是 0**
  → 脚本报的 `borders: []`、`backgrounds: []` 属实，**不是漏检**
- 截图里那些深色块 = 项目截图本身（图片），不是样式画出来的
- 全文只有两个真构件：**大号红数字序号** 和 **下划线**

## 章节头（脚本只归成 accent_text；这是本文最有辨识度的构件，5 处）

```html
<p style="margin-bottom:16px; text-align:center;">
  <span style="font-size:36px;">
    <span style="color:rgb(250,83,89); font-weight:bold; text-decoration:underline;">01</span>
    <span style="color:rgb(178,178,178); font-size:18px;">
      <span style="color:rgb(51,51,51);">Impeccable</span>
    </span>
  </span>
</p>
```

三件套：**居中** + 36px 红色粗体**下划线**两位序号 + 18px 英文项目名。

英文名是**双层颜色**：外层 `rgb(178,178,178)` 浅灰被内层 `rgb(51,51,51)` 深灰覆盖
（渲染出来是深灰）。照抄样式串即可，别自己推哪一层生效。

## 复核过程中我自己踩的坑（留档）

用 `\bsrc=` 去抽图片属性分类时，`\b` 会让它**同时匹配 `data-src=`**，
于是第一遍得出「12 张图的 src 全是 mmbiz 真图」——**是错的**，实际有 10 处是透明占位。
判据要写成 `(^|\s)src=`。

> 同类错误库里已记过多次（缺陷 #6 把空 SVG 当装饰、#7 把 `<mp*>` 笼统数）。
> 这次的新形态是：**量词的边界写宽了，把另一个属性也算进来**。
