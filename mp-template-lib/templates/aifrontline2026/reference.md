## ⚠️ 人工复核清单（**必做**）

`theme.json` 只描述**数值**。数值对 ≠ 模板对。2026-09-30 实测过一次：
颜色/圆角/字号全部解析正确，但**结构错三处**，而且这三处靠读 CSS 推不出来 ——

| 我推出来的 | 实际 | 怎么发现的 |
|---|---|---|
| 章节标题条 = 左标签 + 右胶囊（两端布局） | **红方块 + 英文小字 + 中文标题**（三件套） | 渲染后并排看 |
| 引用块 = 圆角浅底 | 还多一根 **`border-left` 红竖线** | 渲染后并排看 |
| 胶囊 = 纯文字 | 内嵌一个 **6px 小红圆点** | 渲染后并排看 |

**所以请打开 `preview.png`，并排对照原文，逐条确认：**

- [ ] 卡片：圆角多大？阴影是「淡色大扩散」还是「深色小硬边」？有没有边框？
- [ ] 章节标题：是左右两端、还是「色块 + 多行文字」？色块里是数字还是文字？
- [ ] 引用块：左侧有竖线吗？圆角是四角还是只圆右侧（`0 Xpx Xpx 0`）？
- [ ] 标签/胶囊：里面有圆点或图标吗？底色是浅色还是实色？
- [ ] 序号：是圆点、方块、还是数字？圆点里有内容吗？
- [ ] 正文：字号、行高、是否两端对齐（`text-align: justify`）？
- [ ] 有没有**只在少数位置出现**的组件（容易被"最常见值"统计盖掉）？

**优先看出现次数少的组件** —— 高频值会掩盖特例，而特例往往才是模板的辨识度所在。

# 人工复核结果（2026-10-03）

**结论：上面所有数值都属实，但结构漏了一类主构件、误报了一类。**

复核方法：读 `sample.html` 原始标签定位 → 扫 `preview.png` 的**绿色像素**拿到精确 y 坐标 →
逐处裁图放大对照。先扫像素再裁图，比在缩略图上估位置可靠得多。

## ⚠️ 漏报：章节标题（4 处，是这篇最有辨识度的构件）

我按 CSS 数值推出来的是「32px 数字 + 20px 绿字」。**实际多一条图形**：

```
1  ═══════▪────────────────────────────────
   基于Mods：用户可改写Agent内部行为
```

绿色粗短线 + 小绿方块 + 浅灰长线 —— 这三件**是一张背景 PNG 里的内容**：

```html
<p style="font-size:20px; color:rgb(0,179,139); line-height:35px;
          background-image: url(<同一张图，4 处相同>);
          background-repeat: no-repeat;
          background-position: left 28px;
          background-size: 100% 6px;">     <!-- ← 拉成细长条，伪装成一条线 -->
  <span style="display:block; padding-left:22px; font-size:32px;">1</span>
  <section><span style="color:rgb(0,179,139); font-size:20px; font-weight:400">标题</span></section>
</p>
```

**为什么解析器必然漏**：那是栅格图，不是边框也不是背景色。数值层面它只是
「一个 100%×6px 的 background-image」—— 不看图永远不知道它画的是条横线。

**判据**：`background-size` 是细长条（高 ≤ 8px）就是「线」。

## ⚠️ 误报：`svg_real` 的 4 个「真 SVG」

`svg_real = 4` 看着像「用了 4 个 SVG 图标」，**实际全是圆角补白块**：

```html
<svg viewBox="0 0 2 2" width="4px" height="4px" class="border_filler border_filler_lefttop">
```

`border_filler_lefttop / righttop / rightbot / leftbot` —— 四个角各一块，微信编辑器画边框的角料。
`svg_real` 只滤掉了 `width:0`，没滤掉这种。

**判据**：viewBox 极小（如 `0 0 2 2`）且宽高 ≤ 6px，或 class 含 `border_filler`。

> 这已经是**第五次**「同一语义位置、不同实现手法」导致的漏检：
> #4 是底色式标题条（不是下划线式），这次是**背景图横线式**。
> 每次都是「我以为这一类的定义就是第一个样本的样子」。
