# Prompt 审计器

对照 `abacas-cloud` 和 `FSA-Platform` 源码，逐条验证提示词中的每一个事实声明。

## 输入

- 提示词文件路径（`prompts/component-x.md`）
- 或整个页面文件夹（自动找出所有 prompts/）

## 输出

逐一声明审计报告：

| 标记 | 含义 |
|------|------|
| ✅ | 正确，附源码行号 |
| ⚠️ | 方向对但细节有偏差 |
| ❌ | 与源码不符，给出正确表述 |

## 审计范围

对提示词中的以下类型声明强制验证：

| 类型 | 示例 |
|------|------|
| 数字 | "种群20"、"8套公式"、"15个部门" |
| 公式 | "适应度=超标量/达标率²" |
| 逻辑 | "全部达标→fitness=成本" |
| 名称 | "RSM浓度响应"、"SMAT数据融合" |
| 流程 | "6阶段管线"、"三层计算" |

## 源码映射

| PPT 页 | 验证来源 |
|--------|----------|
| 第(2)页 措施量化 | `abacas-cloud/backend/reduction-measures/jjj-cities/` |
| 第(3)页 费效+协同 | `abacas-cloud/backend/cost-evaluation/` + `synergy/` + `rsm/` + `smat/` |
| 第(4)页 反算 | `abacas-cloud/backend/rsm/python/utils/GeneticAlgorithm.py` + `FSA-Platform/` |

## 工作流

1. 读取提示词，提取所有事实声明
2. 对每条声明，搜索对应源码验证
3. 给出 ✅/⚠️/❌ + 源码行号 + 修正建议
4. 汇总审计结论

## 注意

- 必须读源码原文，不依赖记忆
- 多个版本（C#/Python）有差异时，标注版本差异
- 提示词中的简化表述如果方向正确，标记 ⚠️ 而不是 ❌
